## 📦 Installation

Clone the repository

```bash
git clone https://github.com/ORQELIX/Orqelix-portfolio.git
```

Navigate to the project

```bash
cd Orqelix-portfolio
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

---

## 🏗 Build

```bash
npm run build
```

Preview production build

```bash
npm run preview
```

---

## 🚀 Deployment

### GitHub Pages

Deploy using

```bash
npm run deploy
```

The project automatically uses

```text
base: /Orqelix-portfolio/
```

---

### Cloudflare Pages

Framework Preset

```
React (Vite)
```

Build Command

```bash
npm run build
```

Output Directory

```
dist
```

Environment Variable

| Name | Value |
|------|-------|
| CF_PAGES | 1 |

The project automatically switches to

```text
base: /
```
